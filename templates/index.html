Operating Systems Quick Reference & Formulas

CPU Timing Formulas
  • Turnaround Time (TAT): $CT - AT$
  • Waiting Time (WT): $TAT - BT$
  • Response Time (RT): $\text{First Start} - AT$
  • CPU Utilization: $\frac{\sum BT}{\text{Total Elapsed}} \times 100\%$
  • Throughput: $\frac{\text{Completed Processes}}{\text{Total Elapsed}}$
Memory Allocation Rules
  • First Fit: First free block with $Size \ge Request$.
  • Best Fit: Free block with $\min(Size - Request \ge 0)$.
  • Worst Fit: Free block with $\max(Size - Request \ge 0)$.
  • Internal Frag: Unused space inside an allocated partition.
  • External Frag: Free space exists in total, but non-contiguous.
Banker's Algorithm Rules
  • Need Matrix: $Need_{ij} = Max_{ij} - Alloc_{ij}$
  • Safe Condition: $\exists$ sequence where $Need_i \le Work$.
  • Request Step 1: $Request_i \le Need_i$ (else error).
  • Request Step 2: $Request_i \le Available$ (else wait).
  • Grant Rule: Safe state must be maintained.
